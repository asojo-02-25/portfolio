### 確定事項

- エンジニア職・アプリケーションエンジニア職の就職活動に使用する。

## 4. サイト構成

### 確定事項

トップページに自己紹介文と4項目の概要カードを配置する。関連リンクは共通フッターにまとめ、専用ページは設けない。

| 項目 | 扱う内容 | 遷移先の方針 |
| --- | --- | --- |
| 自己紹介・経歴 | 自己紹介とこれまでの経験 | 自己紹介と経歴をまとめたページ |
| プロジェクト | 制作物の紹介 | プロジェクトの紹介ページ |
| スキル | 使用経験のある技術 | スキルの紹介ページ |
| 記事 | 自分が書いた記事 | 記事の一覧・紹介ページ |
| 関連リンク | GitHubなどの関連先 | 共通フッターから外部リンクへ直接移動 |

- 「書いたもの」と「記事」は同じ内容として扱い、表示名を「記事」に統一する。
- モバイルファーストで設計し、draw.ioで画面構成を検討する。
- カードはスマートフォン・PCともに1列で並べ、高さは内容に合わせる。PCではカード内の左にタイトル、右に内容を配置する。
- ページのURL、ナビゲーションの詳細は未確定。
