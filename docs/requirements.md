## 1. 目的と開発方針

### 確定事項

- エンジニア職・アプリケーションエンジニア職の就職活動に使用する。
- まず就活に使えるサイトをできるだけ早く公開する。具体的な期限は未定。
- 時間に余裕ができた段階で、自分の好みに合わせてデザインを改修する。
- 要件定義から対話で進め、Codexアプリ上で開発する。
- 制作物の詳細な技術説明は、作成済みのREADMEを活用する。サイト上の紹介は簡潔にする。
- 要件定義では各ページの掲載内容、必要な機能・導線、初版の範囲と完成条件を整理する。技術選定と具体的な画面構成は後の設計段階で決める。

## 4. サイト構成

### 確定事項

トップページに以下の5項目を配置し、各ページに遷移できる構成とする。

| 項目 | 扱う内容 | 遷移先の方針 |
| --- | --- | --- |
| 自己紹介・経歴 | 自己紹介とこれまでの経験 | 自己紹介と経歴をまとめたページ |
| プロジェクト | 制作物の紹介 | プロジェクトの紹介ページ |
| スキル | 使用経験のある技術 | スキルの紹介ページ |
| 記事 | 自分が書いた記事 | 記事の一覧・紹介ページ |
| 関連リンク | GitHubなどの関連先 | 関連リンクのページ |

- 「書いたもの」と「記事」は同じ内容として扱い、表示名を「記事」に統一する。
- ページのURL、ナビゲーションの配置、トップに掲載する情報量は未確定。
- 関連リンク先への直接リンクをトップにも併設するかは未確定。
